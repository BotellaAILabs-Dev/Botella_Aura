# Environment Variables — Botella Aura

Every environment variable the code reads: what it is for, whether it is required, where in the code it is used, and where and how to get its value. Copy `.env.example` to `.env` locally; set the same names in **Vercel → Project → Settings → Environment Variables** for production.

_Generated from the git history and source code on 30 Oct 2026._

## Minimum to run locally

| Variable | Value |
| --- | --- |
| `DATABASE_URL` | `postgresql://postgres:postgres@localhost:5432/botella_aura?schema=public` |
| `DIRECT_URL` | same as `DATABASE_URL` |
| `NEXTAUTH_URL` | `http://localhost:3000` |
| `NEXTAUTH_SECRET` | `openssl rand -base64 32` |
| `ENCRYPTION_KEY` | `openssl rand -base64 32` |
| `ANTHROPIC_API_KEY` **or** `GEMINI_API_KEY` | an AI key (without one, AI features fall back to labelled templates) |

Check a configuration with `npm run env:check` (add `--production` for production rules) and print every OAuth redirect URI to register with `npm run auth:endpoints`.

## Rules

- **Never** prefix a secret with `NEXT_PUBLIC_` — Next.js inlines those into the browser bundle.
- Never commit `.env`. `.env.example` holds names and empty placeholders only.
- Netlify's secret scanner skips only non-secret keys (`SECRETS_SCAN_OMIT_KEYS` in `netlify.toml`).
